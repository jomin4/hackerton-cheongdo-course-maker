# 프로젝트 개요 — 청도 코스 메이커

> 상태: 확정 · 최종 수정 2026-11-01 (v2 하루 일정)

## 한 줄 소개

자가용으로 청도에 당일치기로 오는 사람이 **방문 날짜 · 시작 · 끝 시각, 동행, 관심사**를 고르면, 그날 문을 연 곳만으로 관광 · 점심 · 쉬어 가기 · 저녁 · 야간 관광을 시각과 이동 시간까지 적은 하루 일정으로 보여주는 웹 서비스.

## 배경과 목적

- **2026 청도 바이브코딩 해커톤**(2026-11-05~06, GitHub Copilot + Azure Cloud 필수) 대비 연습 프로젝트.
- 연습이지만 결과물은 **실제 사용할 수 있는 프로덕션 웹**을 목표로 한다.
- 해커톤 당일 흐름(기획 → Copilot 구현 → Azure 배포 → 제출)을 미리 끝까지 한 번 경험한다.

## 풀려는 문제

처음 청도를 찾는 사람은 운문사, 와인터널, 레일바이크 같은 장소를 알더라도 **어디부터 어떤 순서로, 몇 시에 가야 문이 열려 있는지, 점심 · 저녁은 어디서 먹을지** 알기 어렵다. 장소마다 체류 시간 · 위치 · 운영시간 · 휴무일이 달라 직접 하루 일정을 짜려면 검색과 계산이 필요하다.

## 범위

| 포함 (MVP) | 제외 (이후 확장 후보) |
|---|---|
| 조건 선택 → 하루 일정 → 장소 상세 | LLM 기반 추천 |
| URL로 코스 공유 | 데이터베이스, 로그인, 리뷰·사진 업로드 |
| 로딩·빈 결과·오류 상태 화면 | 지도 표시, 실시간 교통 |
| Azure VM 운영 배포 (VM에서 소스 빌드, HTTPS는 선택) | 다중 서버, 오토스케일 |

자세한 기능 목록은 [`../01-product/mvp-spec.md`](../01-product/mvp-spec.md).

## 성공 기준

1. 배포된 HTTPS 주소에서 조건 선택 → 코스 결과 → 관광지 상세가 동작한다.
2. 같은 공유 URL을 다시 열면 같은 코스가 나온다.
3. `main` 브랜치에 push하면 테스트 → 이미지 빌드 → VM 배포가 자동으로 끝난다.
4. 개발자가 런북 없이도 VM 생성부터 배포까지 설명할 수 있다.
5. 해커톤 당일용 치트시트가 완성되어 있다.

## 기술 스택 요약

React + Vite + TypeScript + Tailwind / Express + TypeScript / nginx + Docker Compose / Azure VM (Ubuntu 24.04) / 배포는 VM에서 소스 빌드 (CI/CD · 레지스트리 없음).
전체 표와 선택 이유는 [`decisions/0001-tech-stack.md`](decisions/0001-tech-stack.md).
