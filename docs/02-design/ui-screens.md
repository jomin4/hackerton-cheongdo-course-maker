# 화면 구성

> 디자인 원본: claude.ai 디자인 캔버스 "청도 코스 메이커 UI" (아트보드 5개) · 확정 2026-10-29 · v2 하루 일정 반영 2026-11-01 ([설계 7장](../01-product/day-course-design.md#7-화면-변화))
> 토큰: [`design-tokens.md`](design-tokens.md)

## 공통 레이아웃

- **헤더** (높이 64px, 모바일 56px, 하단 1px 테두리): 로고(감색 원 + 꼭지) + "청도 코스" / 메뉴 "이용 방법", "관광지" / 검정 버튼 "코스 만들기"(홈 조건 카드로 이동)
- **본문 폭**: 최대 1200px, 좌우 여백 24px (모바일 16px)
- **푸터**: "운영 정보는 방문 전 공식 안내를 확인해 주세요." · "데이터 제공: ⓒ한국관광공사" · "사진: 한국관광공사 (공공누리 제1유형)" + `© 2026 청도 코스` (모노 글꼴)
- **브레드크럼**: 결과 · 상세 페이지 상단 (`홈 / 추천 코스 / 장소명`)
- **사진**: 공공누리 제1유형만, 원본 URL을 자르거나 바꾸지 않고 `object-cover`로 표시, 사진 가까이에 출처(`credit`)를 적는다. 사진이 없으면 사진 영역 자체를 두지 않는다 (상세는 일러스트).

## 01 홈 `/`

| 영역 | 구성 |
|---|---|
| 히어로 (격자 배경 56px) | 좌: 배지 "청도 여행 코스 플래너", 제목 3줄 "청도 여행, / 세 번만 고르면 / 코스가 됩니다.", 설명, 체크 항목 3개(가입 없이 바로 · 이동 시간 자동 계산 · 링크 하나로 공유) |
| | 우: 조건 카드 — 헤더 "코스 조건 · 3 STEPS" / 01 방문 날짜와 시간(날짜 입력 · 시작 선택 · 끝 선택 3칸, 보조 문구 "점심 · 쉬어 가기 · 저녁까지 시간에 맞춰 넣어 드려요.") / 02 누구와 함께(4칸) / 03 관심사(알약 버튼, 다중) / 하단 회색 영역: 선택 요약("11월 7일(토) 10:00–19:00 · 가족 · 자연 · 체험"), 공유 URL 미리보기(`code`), "코스 만들기" 버튼 |
| HOW IT WORKS | 테두리로 이어진 3단 카드 (01 조건 고르기 · 02 잘 맞는 장소 담기 · 03 동선 정리) |
| PLACES | 관광지 카드 6개 (`/api/spots?kind=spot` 앞 6곳). 사진이 있으면 사진 + 출처, 점 패턴 상단에 번호 · 권역 배지, 이름, 요약, 태그, 권역 · 체류 시간 |
| CTA | "이번 주말 청도, 어디부터 갈까요?" + 버튼 |

- 날짜: `<input type="date" min=오늘(KST)>`, 기본 오늘. 시작: 08:00~14:00 30분 단위 `<select>`, 기본 10:00. 끝: 시작 + 3시간~21:00 30분 단위 `<select>`, 기본 19:00. 시작을 바꿔 끝이 범위 밖이 되면 끝을 시작 + 3시간으로 맞춘다.
- 관심사 0개 → 버튼 비활성 + "관심사를 하나 이상 골라주세요". 선택된 버튼은 검정 배경 · 흰 글씨, `aria-pressed="true"`.
- 장소 카드 상태: 불러오는 중 "관광지를 불러오고 있어요", 실패 시 메시지 + "다시 불러오기", 0곳이면 "등록된 관광지가 없어요".

## 02 하루 일정 `/course`

| 영역 | 구성 |
|---|---|
| 상단 (회색 배경) | 브레드크럼, 제목 "11월 7일(토) 가족과 함께하는 청도 하루", 조건 칩(날짜 · 시작–끝 · 동행 · 관심사), 버튼 "조건 수정"(테두리) · "링크 복사"(검정, 클릭 시 2초간 "복사됨". 복사할 수 없으면 "링크를 선택해 복사해 주세요" 입력칸) |
| 좌: 타임라인 (가변) | 안내 상자(`notices`가 있을 때) → 원 + 세로 연결선 타임라인. 원 안은 관광이면 순번, 식사는 수저 아이콘, 쉬어 가기는 컵 아이콘. 카드: 사진 + 출처(있을 때), 종류 배지(관광 · 점심 · 쉬어 가기 · 저녁), 권역 배지, 이름, 도착–출발 시각(`10:00–10:40`), 요약, 일치 태그(감색 연한 배경, 관광만), "체류 N분"(관광) 또는 종류 이름, "상세 보기" |
| 카드 사이 이동 행 | 차 아이콘 "차로 약 12분 · 6.3km", 기다림이 있으면 " · 여유 15분". 첫 항목에 기다림이 있으면 "여는 시간까지 여유 N분" |
| 우: 요약 (폭 280px+) | "일정 요약": 일정 시작–끝(큰 모노 숫자), "선택한 시간 10:00–19:00", 체류 · 이동 · 여유 막대(검정 · 감색 · 회색) + 범례, "관광 N곳", "식사 N번"(없으면 "식사 없음") |
| 우: 빠진 장소 | "이번 일정에서 빠진 장소" — 이름 + 이유 배지("이날 휴무" · "시간 부족"). 처음 5곳만, 나머지는 "N곳 더 보기" / "접기"(`aria-expanded`). 시간 부족인 곳이 있고 끝이 21:00 전이면 "끝 시각을 21:00으로 늦춰 다시 만들기" |
| 우: 계산 가정 | "이동 시간은 직선거리에 도로 보정을 더해 어림한 값이에요. 실제 교통 상황에 따라 달라질 수 있어요." |

카드 사진 높이는 176px(모바일) · 224px(640px 이상)로 고정한다. 768px 미만에서는 한 단으로 쌓인다 (04 참고).

## 03 장소 상세 `/spots/:id`

관광지 · 식당 · 카페가 같은 화면을 쓴다.

| 영역 | 구성 |
|---|---|
| 상단 | 브레드크럼 + "코스로 돌아가기" (`from`이 없으면 홈으로) |
| 대표 이미지 (높이 360px, 모바일 220px, 검정) | 첫 번째 1유형 사진 + 오른쪽 아래 출처 표기. 사진이 없으면 터널 아치 일러스트 |
| 제목 영역 | 종류 · 권역 칩, 태그, 이름(48px), 한 줄 소개 / 버튼 "주소 복사" · "지도에서 보기"(카카오맵 좌표 링크 `https://map.kakao.com/link/map/{이름},{위도},{경도}`, 새 탭, `rel="noopener noreferrer"`) |
| 좌: 본문 | 소개(문단), 방문 팁(번호 목록), 가까운 관광지(카드 최대 3개: 권역, 이름, 요약, 체류, 사진 + 출처) |
| 우: 이용 정보 | 주소, 운영시간(`formatWeeklyHours` 줄, 예 "화~일 09:30–18:00" · "월 휴무", 입장 마감이 있으면 "닫기 15분 전 입장 마감"), 안내(`hours.note`), 식사(식당만, "점심 · 저녁"), 요금, 전화(`tel:` 링크), 체류 + "출처: {source} · {checkedAt} 기준. 방문 전 확인하세요." |
| 우: 이 코스에서 (`from`이 있을 때) | "하루 일정 N / 전체번째 · 도착–출발", 이전 · 다음 항목(이름 + 종류 칩, 다음은 "차로 약 N분"), "코스 전체 보기" |

## 04 모바일 (390px)

- 헤더 56px, 메뉴는 햄버거 버튼(`aria-label="메뉴 열기"`)
- 결과 상단: 제목 2줄, 조건 칩, 버튼 2칸 그리드
- 결과 순서: **요약 → (안내) 타임라인 → 빠진 장소 · 계산 가정**
- 이동 행 · 카드 글자는 줄바꿈되고, 가로 스크롤이 생기지 않는다

## 05 상태 화면

| 상태 | 표시 | 행동 |
|---|---|---|
| 로딩 | 제목 · 칩 · 카드 스켈레톤 + "코스를 계산하고 있어요" (`role="status"`) | — |
| 빈 결과 (200, 관광 0곳) | 돋보기 아이콘, "조건에 맞는 장소를 찾지 못했어요", "10:00–19:00 안에 담을 수 있는 '자연, 체험' 장소가 없어요. 끝 시각을 늦추거나 관심사를 더 골라보세요." | "끝 시각 늦추기"(끝 21:00 전일 때), "관심사 더 고르기" |
| 400 | 경고 아이콘, "조건을 다시 확인해 주세요", 문제 값을 강조한 URL 코드, API 메시지, 허용 값 안내 "방문 날짜(오늘 이후), 시작 08:00~14:00, 끝은 시작 3시간 뒤~21:00(30분 단위), 동행, 관심사를 확인해 주세요." | "조건 다시 고르기" |
| 오류 (네트워크 · 500) | "잠시 문제가 생겼어요" + 메시지 (연결 실패면 "서버에 연결할 수 없어요. 잠시 후 다시 시도해 주세요.") | "다시 시도" |
| 404 장소 | 모노 글꼴 "404", "찾는 장소가 없어요" | "장소 목록으로", "홈으로" |
| 404 경로 | 모노 글꼴 "404", "페이지를 찾을 수 없어요" | "장소 목록으로", "홈으로" |

## 접근성 체크

- 모든 선택 버튼은 실제 `<button>` + `aria-pressed`, 그룹은 `<fieldset>` + `<legend>`, 날짜 · 시각 입력은 `<label>`로 감싼다
- 터치 영역 최소 44px, 글자 12px 이상
- 텍스트 대비 4.5:1 이상 (회색 글자는 `#666666` 이상 진하게)
- 아이콘만 있는 버튼은 `aria-label`, 장식 SVG는 `aria-hidden="true"`, 사진은 우리가 쓴 `alt`
- 새 탭 링크는 `rel="noopener noreferrer"`
- 이모지 사용 안 함, 아이콘은 인라인 SVG(라인 스타일)
